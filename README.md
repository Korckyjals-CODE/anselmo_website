# AnselmoBot.com

Static marketing site for [Anselmo](https://anselmobot.com) — an email-based Office automation bot (Excel, Word, PowerPoint, text) by Korckyjals-CODE.

Published with GitHub Pages from the `main` branch. Custom domain: `anselmobot.com` (see `CNAME`).

Spanish is the default language; English is switched client-side (`?lang=en` or the language buttons).
